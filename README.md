# Aurora's Node Manager

> [English →](README.en.md)

一个 Blender 插件，通过 JSON 序列化实现节点模式的保存、加载和共享。支持着色器、合成器和几何节点，具备跨版本和跨类型兼容能力。

## 创作动机

最开始，我只是想写一个节点管理器——每次都要重新搭建节点组，实在太烦了。
用 .blend 文件存当然可以，但对我这台磁盘容量捉襟见肘的电脑来说，体积太大了。JSON 就轻量得多。

而且 JSON 是纯文本，最简单的分享方式就是直接在社交媒体上发送文本。这样一来恰好可以绕开网盘。
国内节点分享大多依赖网盘（我其实不知道国外是如何分享的）。但我一直很讨厌它们：总是企图侵略性地取代你电脑默认的文件打开方式和默认浏览器选项。不用又不行，这种"不得不用"的感觉太恶心了。

用 JSON 分享节点模式，刚好同时解决了这两个问题：省空间，避开网盘。
如果你也受够了搭节点和网盘，可以试试这个。
（学生党，更新维护可能比较慢，见谅🙏）

## 核心特性

- **一键保存/加载** — 选中节点保存为模式文件，随时加载恢复。
- **跨类型复用** — 着色器节点可在几何节点或合成器中加载使用。
- **跨版本兼容** — 支持 Blender 3.6+ 到 5.x。
- **模式锁定** — 锁定模式以防止误覆盖或误删除。
- **ZIP 导入/导出** — 将模式打包为 ZIP 文件分发，嵌套节点组也能完整保留。
- **剪贴板分享** — 复制模式为 JSON，粘贴到论坛或聊天消息中分享。
- **多语言 UI** — 原生支持英文和中文界面。

## 技术实现

- **RNA 属性发现**：运行时自动扫描节点全部 RNA 属性并序列化，无需手动维护属性列表，支持类型推断。
- **UUID 拓扑系统**：每个节点分配 UUID，连线通过插槽标识符和索引匹配，使用 Kahn 算法拓扑排序确保加载顺序正确。
- **智能枚举兼容**：跨版本加载时，不存在的枚举值自动按优先级匹配最接近的可用选项。
- **索引优先插槽匹配**：反序列化时按 `index` → `identifier` → `name` → `type` 优先级查找插槽，提高连接成功率。

## 安装方法

1. 下载插件 ZIP 文件
2. Blender → 编辑 → 偏好设置 → 插件 → 安装
3. 选择 ZIP 文件并启用插件
4. 打开节点编辑器，按 N 键显示侧边栏，找到 **Dear.Aurora** 标签页

## 使用方法

插件在节点编辑器侧边栏提供三个面板：

### 节点模式（主面板）
- **分类标签**：切换着色器 / 合成器 / 几何节点
- **保存选中节点**：将选中的节点保存为命名模式
- **加载**：将模式加载到当前节点树
- **覆盖**：用当前选中的节点替换已有模式
- **复制**：将模式以 JSON Bundle 格式复制到剪贴板
- **粘贴**：从剪贴板导入模式
- **导出/导入**：以 ZIP 文件格式导出/导入模式
- **编辑**：编辑模式元数据（名称、描述、作者、标签）
- **锁定/解锁**：防止意外修改
- **删除**：删除模式

### 模式信息
显示选中模式的元数据：描述、作者、创建日期、版本、节点/组数量和类型。

### 高级
拟定添加序列化选项（目前预留，后续版本开放）。

## 兼容性

于 3.6.1、4.1.1、4.5.2 LTS、5.1.1 LTS 测试，均可兼容。

支持中文和英文界面语言（中文有一些字段可能匹配不上）。

## 文件结构

```
aurora_nodes_manager/
├── __init__.py              # 插件入口、偏好设置
├── core/
│   ├── serializer.py        # 序列化引擎
│   ├── deserializer.py      # 反序列化引擎（RNA 驱动）
│   ├── rna_inspector.py     # RNA 属性发现引擎
│   ├── topology.py          # Kahn 拓扑排序
│   ├── properties_db.py     # 遗留包装器（委托给 RNAInspector）
│   └── zone_handler.py      # Zone 节点（Simulation/Repeat）处理
├── compat/
│   ├── blender_compat.py    # API 兼容层、插槽值读写
│   └── node_mappings.py     # 跨版本和跨类型节点映射
├── io_module/
│   └── operators.py         # 所有操作符（保存/加载/删除/编辑/覆盖/锁定/迁移/导出/导入/复制/粘贴）
├── ui/
│   └── panels.py            # 3 个面板：主面板、信息面板、高级面板
└── utils/
    ├── file_utils.py        # 文件工具、ZIP Bundle 处理
    └── translations.py      # 中文翻译字典
```

模式以 `.json` 文件形式存储在插件的 `patterns/` 目录下，按类型分类（`shader/`、`compositor/`、`geometry/`）。嵌套节点组保存为独立的 `_group_*.json` 侧边文件。

## 已知限制

- Zone 节点（Simulation Zone / Repeat Zone）的内部结构反序列化存在插槽丢失问题，加载后可能需要手动重连。
- 自定义 Python 节点需要手动添加支持。
- 节点映射可能未覆盖所有节点类型。跨版本加载可能因 API 重构产生参数错误或渲染差异（最坏情况会因为异常索引值导致 Blender 崩溃）。
- 节点布局位置偶有偏移。
- 非常复杂的节点组通过剪贴板导出可能超出社交媒体字数限制。大模式文件请使用 ZIP 导出。
